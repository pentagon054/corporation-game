# Corporation v34.3 — Business Upgrade Fix

Исправлен баг, из-за которого после нескольких подтверждений кнопки прокачки бизнеса могли перестать реагировать.

Причина: старый таймер закрытия кастомного окна мог скрыть уже следующее окно подтверждения. Его Promise оставался незавершённым, а защита от повторного действия оставалась заблокированной.

Что изменено:
- отменяется старый таймер закрытия перед открытием нового окна;
- старое окно не может скрыть более новое;
- обработчики окна очищаются при закрытии/замене;
- добавлен token lifecycle, чтобы устаревшие обработчики не влияли на новое окно;
- обновлены cache-busting версии скриптов до v343.

Установка: распаковать ZIP в корень папки игры с заменой файлов.
