## Дополнительные исправления

- Атомарная продажа бизнеса: из двух одновременных запросов проходит один; второй отклоняется.
- История сохраняет до 720 наблюдений на каждую бумагу. Минутные изменения и новости обрабатываются хронологически.
- Формирование свечей привязано к времени; открытие следующей свечи использует предыдущее закрытие. Последняя свеча может быть незавершённой. Пропуски без котировок не заполняются вымышленными ценами.
- Расписание новостей и розыгрышей сохраняется при перезапуске; проверены границы джиттера 60–105 минут, однократность часового розыгрыша и рост паттерна.
- Админский allowlist проверен с корректно подписанными разными ID, поддельной подписью, просроченными данными и X-User-Id.
- Ограничение chunked-тела без Content-Length, отключение dev-auth в production.
- Текст названий и ошибок экранирован, modal использует textContent. Кнопка modal остаётся выше нижней панели на 320 px.
- Новые акции и по шесть новостей проверены, миграция сохраняет владение.

## Запуск тестов

```bash
python -m pip install -r requirements.txt
PYTHONPATH=. python tests/test_audit.py
PYTHONPATH=. python tests/test_v24.py
```

18 серверных тестов прошли (8 базовых + 10 новых). Дополнительно прошёл jsdom-набор реальных обработчиков UI и Chromium-набор четырёх ширин, городов, порогов баланса, свечей, рейтинга, безопасного текста и закрытия модального окна. Для JS-тестов зависимости jsdom/playwright устанавливаются отдельно; они не нужны production-сервису.

Визуально просмотрены мобильные экраны бизнеса, карты и каталога недвижимости, а также обе новые VIP-фотографии. Скриншоты снимались Chromium на desktop, не физическим телефоном.

## Границы проверки

Полноэкранный режим реализован по Telegram API 8.0+, но реальный Telegram на iOS/Android здесь не запускался. Отдельно проверь его после выкладки. Native prompt/confirm в тестах ввода заменялись адаптером; полностью ручная проверка диалогов остаётся проверкой на устройстве. Нагрузочная ёмкость Railway, устойчивость к распределённому DDoS, независимый пентест и точный баланс нового рынка не сертифицировались. Гарантии «багов больше нет» не даётся.
