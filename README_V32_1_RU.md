# Corporation v32.1 — startup hotfix

Исправления:

- устранён случайный `businessIcon24 is not defined` при первом рендере;
- добавлен boot barrier: `/api/state` и другие игровые API не отдаются фронтенду до загрузки всех игровых JS-модулей;
- добавлен безопасный ранний fallback `businessIcon24`;
- экран обязательной подписки больше не мелькает у уже подписанного пользователя;
- во время быстрой фоновой проверки отображается только обычный тёмный фон Corporation;
- экран подписки появляется только если Telegram реально сообщает, что пользователь не подписан, либо если проверка завершилась ошибкой;
- версии CSS/JS изменены на `v=321`, чтобы Telegram WebView не держал старый кэш.

Серверная защита v32 (`getChatMember`, проверка `initData`, `REQUIRED_CHANNEL`) не ослаблена и не изменена.
