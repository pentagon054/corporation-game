CORPORATION v19 — ADMIN PANEL
=============================

ЧТО ДОБАВЛЕНО
- Закрытая админ-панель: /admin.
- Доступ только для Telegram ID из переменной ADMIN_IDS.
- Кнопка «Админ-панель» в /start только для администратора.
- Команда /admin.
- Команда /myid — показывает твой Telegram ID.
- Глобальная заморозка игры (read-only режим для игроков).
- Во время заморозки не двигаются акции и не начисляется пассивный доход.
- Разморозка не начисляет доход за время паузы.
- Завершение сезона с фиксацией итогового рейтинга.
- Полный сброс прогресса всех игроков.
- Новый сезон: backup -> reset -> новый season_id -> автоматическая разморозка.
- Автоматический backup SQLite перед reset и новым сезоном.
- Ручной backup из админ-панели.
- Просмотр игроков и их показателей.
- Общая статистика экономики.
- История сезонов.
- Журнал действий администратора.
- Backend/API защита: заморозка действует на сервере, а не только на кнопках интерфейса.

ВАЖНО
Архив НЕ содержит corporation.db и НЕ заменяет текущую базу игроков.
При первом запуске app.py сам добавит новые таблицы game_state, season_results и admin_logs в существующую БД.

КАК УСТАНОВИТЬ
1. Распакуй содержимое архива в корень проекта Corporation с заменой app.py и bot.py.
   Папка web получит только новый файл admin.html; существующие index.html/app.js/style.css не заменяются.
2. В Telegram напиши своему боту /myid и скопируй Telegram ID.
3. В Railway добавь переменную окружения на ОБА сервиса:
   ADMIN_IDS=ТВОЙ_TELEGRAM_ID
   Например: ADMIN_IDS=123456789
   Несколько админов: ADMIN_IDS=123456789,987654321
4. Убедись, что BOT_TOKEN и WEBAPP_URL остались как раньше.
5. После redeploy напиши боту /start: у администратора появится кнопка «🛠 Админ-панель».
   Также можно открыть её командой /admin.

BACKUP
На Railway резервные копии создаются рядом с corporation.db внутри подключённого Volume:
admin_backups/corporation_YYYYMMDD_HHMMSS_*.db

ПОДТВЕРЖДЕНИЯ ОПАСНЫХ ДЕЙСТВИЙ
Завершить сезон: END SEASON
Сбросить весь прогресс: RESET SEASON
Начать новый сезон: NEW SEASON
