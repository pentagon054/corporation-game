# Corporation v27 — рейтинг и приватная операция владельца

## Исправлено

- Кнопки «Вверх» и «Я» рейтинга вынесены из прокручиваемого контента в `document.body` и закреплены относительно viewport справа по центру. Они не уезжают при длинном рейтинге и удаляются при выходе из экрана рейтинга.
- Исправлена операция изменения баланса из закрытого интерфейса владельца. Сервер теперь проверяет фактическую разницу баланса внутри транзакции до commit.
- Сумма учитывается в `total_earned`, прибыли текущего дня и выбранном источнике дохода.
- Операция владельца не попадает в общий журнал администраторов; для неё используется отдельный `owner_logs`.

## Приватность функции владельца

- Публичный `v22_admin.js` больше не содержит текста, кнопки, URL или логики начисления денег.
- Приватный модуль выдаётся сервером только после авторизованного запроса владельца.
- Обычный администратор не получает сведения о наличии расширения в `/api/admin/overview`.
- Запрос приватного модуля или операции не-владельцем получает `404`.
- Если `OWNER_ID` не задан и в `ADMIN_IDS` ровно один ID, этот единственный администратор автоматически считается владельцем.
- Если администраторов несколько, обязательно укажи `OWNER_ID` в Railway.
