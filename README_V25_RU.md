# Corporation v25 — автопарки, точная карта и премиальный интерфейс

Обновление устанавливается поверх v24.1 без сброса прогресса. База данных и `.env` в архив не включены.

## Что изменилось

- Карта и точки городов находятся на одной трансформируемой плоскости: координаты больше не пересчитываются и метки не «шатаются» при перемещении.
- Дорогая недвижимость получила отдельную премиальную подачу, коллекционные преимущества и повышенную доходность VIP-сегмента.
- Все изображения новостей приведены к чёткому формату 1600×900; карточка использует одно фото на всю область 16:9.
- Карточки прокачки бизнеса упрощены: название, эффект и цена без перегруженных строк.
- Базовая доходность обычных бизнесов снижена примерно на 15%.
- Реакция котировки на игровую новость ограничена 10% с учётом ценового пола и потолка.
- Американская облигация удалена. При первом запуске после обновления старые позиции автоматически выкупаются по прежнему номиналу 2 000 ₽ за штуку.
- «Доставка» заменена на такси; существующие активы «Доставки» автоматически переносятся в такси.
- Добавлена отдельная логистическая компания.
- В такси и логистике по четыре вида транспорта с нарисованным видом сбоку, покупкой и продажей машин.
- Гараж начинается с 5 мест, расширяется по таймеру до 10, 20, 35, 55, 75 и 100 мест. Каждый следующий этап дороже и дольше.
- Полная стоимость машин и оплаченных расширений входит в капитализацию бизнеса.
- Кнопки «Вверх» и «Я» в рейтинге закреплены в правой нижней части над навигацией.
- Основные пиктограммы и изображения транспорта нарисованы локальными SVG в стиле игры; системные emoji удаляются из интерфейса.
- Описания акций переписаны кратко и конкретно.

## Миграция

`init_db()` выполняет миграцию автоматически и идемпотентно:

1. создаёт таблицы `transport_fleets` и `transport_vehicles`;
2. переносит `delivery` в `taxi`;
3. создаёт базовые гаражи для уже существующих транспортных компаний;
4. возвращает деньги за `ofz_us` и удаляет старые позиции;
5. сохраняет все остальные активы, историю рынка и игроков.

Перед деплоем всё равно рекомендуется сделать резервную копию Railway Volume.

## Проверка

```bash
python -m unittest discover -s tests -v
node --check web/interactive_map.js
node --check web/premium_v25.js
```

Серверный набор содержит 22 теста, включая автопарк, вместимость, таймер расширения, капитализацию, миграцию облигаций, торговлю, рынок, рейтинг и контроль администраторов.

## Деплой

После распаковки архива в корень репозитория:

```bash
git add app.py bot.py market_v24.py security_v24.py requirements.txt Procfile .env.example ASSETS.md README_V24_RU.md README_V24_1_RU.md README_V25_RU.md web tests
git commit -m "v25: add fleet businesses and premium interface"
git push origin main
```

После успешного деплоя заново открой игру из меню бота. Версия ссылок и статических ресурсов — `250`.
