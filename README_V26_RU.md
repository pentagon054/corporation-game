# Corporation v26.1 — Smoothness / Live UI / Stability Fix

Обновление собрано поверх `Corporation_v26_STABILITY_UI_FIX`.

## Что исправлено

- В рейтинге кнопки `Вверх` и `Я` теперь находятся в отдельном viewport-слое и остаются справа по центру экрана при любой прокрутке, в том числе в Telegram WebView и на устройствах с safe-area.
- Исправлена разметка расширения гаража в такси и логистике: таймер больше не перезаписывает иконку/текст и не вызывает наложение элементов.
- Все live-таймеры переведены на единый секундный scheduler и серверные часы. Состояние содержит `server_time_ms`, поэтому отсчёт не зависит от часов телефона и обновляется по границе реальной секунды.
- После завершения таймера нужный раздел автоматически получает актуальное состояние с сервера.
- Закрытая сервисная операция владельца в админ-панели переведена с системных `prompt()` на собственное стабильное окно и выполняется атомарно на сервере.
- Закрытая операция доступна только `OWNER_ID`: другим администраторам сервер отвечает `404`, capability не отдаётся, записи операции не попадают в их админ-логи, endpoint исключён из OpenAPI schema.
- Если в `ADMIN_IDS` только один ID, он автоматически считается владельцем. Если администраторов несколько, укажи свой Telegram ID в `OWNER_ID` в Railway Variables.
- Статика получила версию `v261`, чтобы Telegram/WebView не оставлял старые JS/CSS в кэше.
- Убраны лишние глобальные `MutationObserver`, тяжёлые containment-правила больше не применяются ко всем `section/article`, фоновые обновления стали реже и дешевле.
- Переходы между вкладками заменены на короткое мягкое изменение прозрачности без резкого вертикального сдвига.
- Для длинных рейтингов и тяжёлых карточек включён `content-visibility`, изображения грузятся лениво, скрытый WebView не тратит лишние animation frames.
- Сохранено восстановление позиции прокрутки после покупок/продаж/улучшений.
