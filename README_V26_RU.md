# Corporation v26 — Stability / UI Fix

Обновление собрано поверх `Corporation_v25_FLEET_PREMIUM`.

## Исправлено

- Покупка машин больше не завязана на системный `prompt`: добавлено игровое окно количества. Повторные покупки не теряют обработчик.
- После покупки, продажи, улучшения и других транзакций сохраняется текущая позиция прокрутки. Это применяется к бизнесам, автопарку, акциям, облигациям, недвижимости и налогам.
- Карта переработана для более чёткого масштабирования: масштаб ограничен разумным диапазоном 1×–6×, слой карты физически переразмеряется вместо экстремального CSS-масштабирования, координаты округляются, убраны фильтры, маркеры остаются резкими.
- Таймер расширения гаража, налоговый дедлайн и таймер реакции котировки на новость обновляются каждую секунду.
- В админ-панели добавлено начисление произвольной суммы игроку с категорией: бизнес, дивиденды, облигации, аренда, прибыль от акций, приз/бонус, прочее или только баланс.
- Начисления по категориям сохраняются в `income_breakdown`; статистика игрока показывает источники прибыли. Вариант «Только баланс» не раздувает показатель общей прибыли.
- Добавлен журнал `admin_income_events` для административных начислений.
- Ярко-жёлтая палитра заменена на приглушённое премиальное золото во всех найденных стилях, включая графики и кнопку обновления.
- Восстановлена иконка раздела акций.
- Исправлено выравнивание иконки IT-студии.
- Карточки акций используют настоящие логотипы брендов; предусмотрен текстовый fallback, если внешний CDN недоступен.
- Фото в новостях переключены на изображения с официальных сайтов / newsroom компаний; при невозможности загрузки автоматически используется локальная резервная картинка.
- Кнопки «Вверх» и «Я» в рейтинге закреплены справа по вертикальному центру экрана и остаются доступными при прокрутке.

- `python -m py_compile app.py bot.py` — OK.
