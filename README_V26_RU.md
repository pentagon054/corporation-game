# Corporation v26.2 — Admin Grant / Live Garage Timer / Fast News

Сборка поверх v26.1.

## Исправлено

- В штатном разделе админ-панели `Игроки` у владельца появилась заметная кнопка `💰 Начислить деньги` у каждого игрока.
- В окне начисления можно указать сумму, категорию статистики и комментарий. Категория `Только баланс` не увеличивает прибыль игрока.
- Серверный endpoint начисления остаётся owner-only и исключён из OpenAPI. Другому администратору он отвечает `404`, capability и записи grant-операций ему не показываются.
- `OWNER_ID` имеет приоритет. Если он не задан, владельцем считается первый Telegram ID, записанный в `ADMIN_IDS`.
- Акция `google` во всей игре отображается как `Google`; старое имя `Alphabet (Google)` удалено.
- Новостная лента больше не зависит от медленных внешних CDN: изображения раздаются локально из `/static/news/`.
- Для каждой новости используется полноразмерный WebP 1600×900 и мобильный WebP 960px через `srcset`; первая карточка загружается с высоким приоритетом, остальные lazy-load.
- Новостные изображения кэшируются браузером/WebView на 7 дней и имеют version query `v=262`.
- Таймер расширения гаража такси и логистики переведён на постоянный live-clock: один scheduler с шагом 200 мс обновляет только текстовое значение, а видимая секунда меняется сразу по фактическому серверному дедлайну.
- После запуска расширения live-clock принудительно синхронизируется с `server_time_ms` и начинает тикать сразу, без ожидания следующего общего рендера.
- При возвращении в Telegram Mini App таймер немедленно пересчитывается по серверному времени; после достижения нуля состояние автоматически запрашивается заново.
- Все статические JS/CSS получили cache-bust `v262`.
