# Corporation — Final Alpha v22

Финальный патч перед недельным альфа-сезоном.

- Недвижимость: примерно 3,2%/ч → 4,8%/ч, дорогие объекты выгоднее дешёвых.
- Капитализация недвижимости: +1% за каждый полный 12-часовой период.
- Продажа и общий рейтинг используют выросшую стоимость объекта.
- Новости одной компании не идут подряд; заголовки по возможности не повторяются.
- Сверху появляется кнопка ↻: полное обновление баланса, статистики, рейтингов и котировок.
- Новостная лента получает LIVE-индикатор.
- База данных и Railway Volume не очищаются.

## Установка
Распакуй архив прямо в папку проекта, где находится `app.py`, затем:

```powershell
.\APPLY_UPDATE.bat
```

или:

```powershell
python .\apply_final_alpha_v22.py
python -m py_compile app.py
```

Перед изменением автоматически создаётся папка `backup_before_alpha_v22_...`.
