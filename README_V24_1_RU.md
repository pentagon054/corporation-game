# Corporation v24.1 — интерактивная карта

Полная версия v24 с обновлённой картой недвижимости. Распакуй поверх проекта; прогресс не сбрасывается, база и секреты в архив не включены. Изменения v24 описаны в README_V24_RU.md, описание карты там заменено этим документом.

Карта:
- перетаскивание мышью и пальцем;
- масштаб 1–32×: колёсико, жест двумя пальцами, кнопки +/−, двойной щелчок;
- кнопка ◎ возвращает весь мир;
- нажатие на город открывает его каталог;
- близкие города собраны в одну метку с числом: нажми и выбери город из списка;
- отдельный список всех городов сохранён под картой;
- при возврате из каталога сохраняется масштаб и положение;
- поддержаны клавиатура (стрелки, +/−, Home) и изменение размера экрана;
- фон карты локальный, без внешних тайлов, API-ключей и дополнительных npm-зависимостей в production.

Проверено в Chromium: выбор Лондона/Парижа, мышь, колёсико, двухпальцевый жест через Chrome DevTools Protocol, отсутствие перехода при перемещении, восстановление камеры, клавиатура, неперекрывающиеся активные области на ширинах 320/390/768. Также повторно пройден общий браузерный набор v24 (четыре ширины, сделки/новости/свечи/рейтинг/модальные окна). Физический Telegram на телефоне здесь не запускался.

После распаковки из папки репозитория:

```bash
git add bot.py web tests README_V24_RU.md README_V24_1_RU.md
git commit -m "v24.1: interactive real estate map"
git push origin main
```

Если v24 ещё не установлена, сначала выполни её инструкции установки и добавления всех файлов из README_V24_RU.md, затем добавь README_V24_1_RU.md перед коммитом. Перед обновлением сохрани резервную копию базы. После деплоя заново открой игру из бота (версия ссылок/ресурсов 241).
